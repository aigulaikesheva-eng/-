# Шаблон: Пояснительная записка (к выбору поставщика / обоснованию решения)

Зафиксировано по итогам подготовки пояснительной записки к выбору организации для проведения СОУТ (август 2026, ООО «Авиационные Интерьеры-СН»). Использовать как основу для аналогичных пояснительных записок в дальнейшем.

## Структура документа

1. **Шапка (справа)**
   - «Генеральному директору»
   - Наименование организации
   - Строка для подписи/ФИО адресата (если нужно указать конкретное лицо)

2. **Заголовок (по центру)**
   - «ПОЯСНИТЕЛЬНАЯ ЗАПИСКА» (жирным, крупным шрифтом)
   - Подзаголовок — короткое описание предмета («к выбору организации для проведения ...»)
   - Номер и дата документа

3. **Раздел 1. Основание**
   - Нормативная база, обязывающая провести мероприятие/принять решение (закон, статья ТК РФ и т.п.)

4. **Раздел 2. Объём / предмет**
   - Конкретные параметры задачи (количество, охват, исключения из охвата)

5. **Раздел 3. Процедура выбора**
   - Как и у кого запрашивались предложения, критерии отбора (реестры, аккредитации и т.д.)
   - Сколько предложений получено, сколько организаций рассмотрено дополнительно

6. **Раздел 4. Результаты сравнения**
   - Сводно по каждому варианту: объём, цена, ключевые условия
   - Ссылка на приложение с детальным сравнительным анализом (таблицы выносятся в отдельный документ-приложение, а не в саму записку)

7. **Раздел 5. Обоснование выбора**
   - Маркированный список конкретных причин (цена, соответствие объёму, аккредитация/реестр, опыт, гарантия, репутация, статус МСП и т.п.)
   - Каждый пункт — измеримый факт, не оценочное суждение

8. **Раздел 6. Вывод и предложение**
   - Чёткая формулировка: «прошу согласовать...», с указанием суммы (цифрами и прописью), контрагента, реквизитов (ИНН), срока действия предложения

9. **Приложения**
   - Перечень приложений с указанием количества листов

10. **Подпись**
    - Должность / ФИО (строки для заполнения от руки)
    - Дата

## Стилистические правила

- Деловой, нейтральный тон, без эмоциональных оценок.
- Каждое утверждение о выборе подкреплено фактом из сравнительного анализа (нельзя просто написать "лучший вариант" без цифр).
- Суммы — всегда цифрами и прописью хотя бы один раз (в выводе).
- Детальные таблицы сравнения — выносить в отдельное приложение (конкурентный/сравнительный анализ), а в самой записке — только сводные показатели.
- Проценты/расчётные величины — считать по единой базе на протяжении всего документа и явно указывать, что цифра расчётная (если объём предложения не совпадает с требуемым).

## Связанные документы этого пакета

- `01_Konkurentny_analiz_SOUT.docx` — детальный сравнительный анализ поставщиков (таблицы) — приложение к пояснительной записке.
- `02_Poyasnitelnaya_zapiska_SOUT.docx` — сама пояснительная записка, построена по этому шаблону.
- `03_Sluzhebnaya_zapiska_byudzhet_SOUT.docx` — служебная записка на выделение средств сверх бюджета: структура аналогична пояснительной записке, но с акцентом на разделы «Обязательность мероприятия» → «Объём» → «Выбор исполнителя и стоимость» → «Бюджетная ситуация» → «Прошу:» (конкретные пункты просьбы).
