# Шифровщик ПДн

Локальный инструмент обезличивания персональных данных работников перед работой с Claude.
Один файл `Шифровщик_ПДн.html`: скачать на рабочий компьютер, открыть двойным щелчком (Edge / Chrome / Яндекс.Браузер).
Интернет не нужен, данные никуда не передаются, установка и права администратора не требуются.

## Схема работы

| Шаг | Где | Что происходит |
|---|---|---|
| 1 | Шифровщик, вкладка 1 | Шахматка → файл `…_обезличено.xlsx` (ФИО → коды `РБ-0001`, СНИЛС/телефоны удалены, дата рождения → возраст) |
| 2 | Шифровщик, «Ключ» | Сохранение ключа «код — ФИО — таб. №» в зашифрованный файл `.json` (пароль) |
| 3 | Claude | Загружается только обезличенный файл: своды, выборки, проекты приказов |
| 4 | Шифровщик, вкладка 3 | Ответ Claude (.xlsx/.docx/.pptx/текст) → коды заменяются на ФИО |

Вкладка 2 — обезличивание готовых документов (приказы, служебки, протоколы): ФИО в любых падежах и формах «Фамилия И.О.», «И.О. Фамилия», СНИЛС, телефоны, e-mail, паспорт; очистка автора в свойствах файла.

## Состав

- `Шифровщик_ПДн.html` — рабочий файл (библиотеки встроены).
- `src/shifr.template.html` — исходный код; `src/build.py` — сборка (встраивает SheetJS 0.18.5 и JSZip 3.10.1).
