Ключ соответствия «код — работник»

Ключ — единственное место, где хранятся ФИО. Храните его на рабочем компьютере / сетевом диске отдела. Не загружайте ключ в Claude и другие внешние сервисы.

Открыть ключ

Открывайте один и тот же ключ при каждой работе — тогда у работника всегда один и тот же код.

Сохранить ключ

С паролем ключ шифруется (AES-256-GCM). Пароль не восстанавливается — без него ключ не открыть. Выгрузка в Excel — без шифрования, только для внутреннего использования.

Порядок работы

Первый раз

  1. Вкладка 1: выбрать шахматку, проверить действия по столбцам, нажать «Обезличить и скачать».
  2. Вкладка «Ключ»: задать пароль, «Сохранить ключ». Файл ключа хранить у себя.
  3. В Claude загружать только файл «…_обезличено.xlsx».

Последующая работа

  1. Вкладка «Ключ»: открыть сохранённый ключ.
  2. Новые/обновлённые таблицы — вкладка 1 (новые работники получат следующие коды, старые — прежние). Документы — вкладка 2.
  3. Ответ Claude (таблица, приказ, выборка) — вкладка 3: коды заменяются на ФИО.
  4. Если ключ дополнился — сохранить его заново.

Текст для Claude (вставить в начало запроса)

В данных работники обозначены кодами вида РБ-0001. Персональные данные удалены намеренно. Используй коды как идентификаторы работников: не изменяй, не склоняй, не сокращай и не объединяй их; в таблицах, списках и текстах приказов указывай работника только кодом в точном написании.

Рекомендации по столбцам

  • ФИО (одним столбцом или Фамилия/Имя/Отчество) — «Код».
  • Табельный № — «Таб. № → в ключ»: используется для однозначного сопоставления, в результат не попадает.
  • Дата рождения — «Возраст» или «Год»; если для задачи не нужна — «Удалить».
  • СНИЛС, паспорт, адрес, телефон, e-mail, ИНН, сведения о здоровье — «Удалить».
  • Должность, подразделение, профессия, класс условий труда, даты медосмотров/инструктажей/обучения — «Оставить».

Ограничения

  • Обезличенные данные с ключом у оператора остаются персональными данными (152-ФЗ). Защита достигается тем, что получатель не имеет ключа.
  • Уникальное сочетание признаков (единственный работник в должности, редкая профессия + возраст) позволяет установить человека. Для таких выборок удаляйте лишние столбцы или укрупняйте значения.
  • В документах проверьте раздел «Возможные упоминания» в отчёте: фамилия без имени и инициалов автоматически не заменяется.
  • Не заменяются ФИО внутри картинок, сканов, PDF и подписей-изображений.
  • Ключ хранится только в этом окне до закрытия. Перед закрытием сохраните ключ.
